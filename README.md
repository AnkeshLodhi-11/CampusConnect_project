# 🎓 CampusConnect – UEC Student Companion

CampusConnect is a Flutter-based student companion application designed for
students of Ujjain Engineering College (UEC).

The main goal of this project is to provide students with a single platform
where they can access academic information, college-related resources,
timetable, attendance, assignments, notices and student support services.

---

## 📱 About the Project

CampusConnect is developed as a college student management and academic
companion application.

The application provides a clean and simple dashboard where students can
quickly access important academic and college-related features.

The project is currently being developed as a Flutter application and is
planned to be extended into a complete Android mobile application.

---

## ✨ Features

### 🏠 Dashboard
- Student-friendly dashboard
- Quick access to important sections
- Clean and responsive UI
- Easy navigation between different modules

### 📚 Subjects & Syllabus
The application contains the current academic subjects and syllabus.

#### Theory Subjects
- Fundamentals of Data Science
- Microprocessor and Interfacing
- Automata and Compiler Design
- Software Engineering and Project Management
- Computer Network

#### Practical / Lab
- Mobile Application Development Lab
- Automata & Compiler Design Lab
- Microprocessor Lab
- Fundamentals of Data Science Lab
- Artificial Intelligence Lab
- Computer Networks Lab

Students can view subject information and syllabus details from the
Subjects section.
